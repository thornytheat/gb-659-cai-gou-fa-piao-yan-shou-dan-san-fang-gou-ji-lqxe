# 数据字典

- run_id：规则版本、映射版本与输入 SHA-256 前 12 位组成的稳定批次标识。
- batch_id：与 run_id 相同；批次一旦建立即绑定建批时的 mapping_version，后续读取按该版本解释。
- mapping_version：只追加的映射版本号；每次纠错发布生成新版本，历史版本内容不可改写。
- mapping_content_sha256：发布时对别名表规范化 JSON 计算的摘要，用于识别内容相同的重复发布。
- publication_key：发布幂等键（调用方提供或由基准版本与内容摘要生成），同一键只产生一个版本。
- base_version：发布时的基准版本；与当前最新版本不一致即拒绝（STALE_VERSION），避免覆盖他人已发布版本。
- line_no：从 1 开始的物理来源行号，不因隔离或排序改变。
- business_key：本项目声明的业务唯一键，始终按字符串存储。
- reason_code：隔离原因的稳定英文编码。
- accepted：进入业务计算的记录数。
- quarantined：保留证据但不参与业务计算的记录数。
- 数值：金额、税额、用量和权重使用 Decimal；对外序列化为字符串。
- 时间：存储为带偏移的 ISO 8601，分桶使用半开区间。
- 空值：缺失键、空串和业务哨兵分别记录。
- 幂等：完整输入字节与规则版本、映射版本相同则复用 run_id，不新增结果；同一原始输入可按另一映射版本另建批次。
